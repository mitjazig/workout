# Izziv 10

10-dnevni wellness PWA (prehrana brez tehtanja, gibanje, mindset). Deluje offline, napredek v localStorage.

## Zagon

```bash
npm install
npm run dev
```

Odpri http://localhost:5173/

Priporočeno: Node.js 20.19+ ali 22.12+.

## Kaj vsebuje

- 10 dni z dnevnimi koraki (prehrana / gibanje / mindset / preverjanje)
- Timer, označevanje napredka, opomniki
- PWA (namestitev na zaslon, offline)

## Opomba

Aplikacija je izvirna in ni povezana z Metodo Virtu / Challenge10official – le podobna ideja 10-dnevnega izziva.
